# kit

A collection of small, self-contained tools that were previously kept in
separate private repositories. They were private because they seemed like
distractions, not because they were secret — so they live here instead, public
and under one licence.

| directory | what it is |
|---|---|
| [`validatecsv/`](validatecsv/) | One RFC 4180 CSV validator implemented four times — Ragel-generated C and C++, C# on .NET 8, and static-musl Rust — plus a shared sample corpus of edge cases. |
| [`qr/`](qr/) | QR "tape" encoder/decoder in C++, over a Reed–Solomon codec (`librs/`) with CRC framing. |
| [`rxengine/`](rxengine/) | A prescription-schedule parser and inventory calculator. ANTLR 4 grammar, C# on .NET 8. Reads `.rx` files describing drugs, doses and purchases, and reports remaining quantity and refill dates. |

ANTLR runtime itself is consumed as a NuGet package and is not vendored here.

## A note on `rxengine`

This is the **engine only**. The `.rx` files it reads are personal medical
data, and none are included — the examples in `rxengine/README.md` are
synthetic. If you want to use it, write your own `.rx` files.

## History

This repository starts with a single commit. The tools' earlier history lived
in separate repositories and is not carried over, deliberately: `rxengine`'s
history contained real prescription data, and starting clean was safer than
filtering it.
